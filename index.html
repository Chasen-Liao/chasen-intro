About
me.

我是 Chasen，广东财经大学计算机科学在读。Pi Agent、Codex、Claude Code 发烧友、vibecoding 资深玩家——几乎每天都在用 AI 把想法 build 成新东西。Chasen 取自「chase」：不断追逐，无限进步。

能力上，我擅长 AI Agent / RAG 系统的工程化落地——从 Hybrid 检索、记忆架构，到前端工程化与桌面客户端，习惯一个人打通从想法到上线的全链路。兴趣在 AI 的边际与商业应用：日常用 Pi Agent、Codex 与 Claude Code 写代码，用 OpenDesign 出设计，配合 LangGraph、React/TS 把一句想法快速 build 成上线产品，也爱折腾工具链、写技术随笔，把每次探索都沉淀下来。

目前正在寻找AI Agent 工程师 | AIGC 工程师方向的机会，愿意在 Agent 工程链路、RAG 系统、AIGC 应用到前端工程化全链路投入。

我是 Chasen，一名 AI 原住民和 Vibe Coding / AI Agent 实战玩家。比起只讨论概念，我更喜欢把新工具放进真实项目里，用能运行的结果验证它。

我在 X 上持续分享 Pi Agent、Codex、Claude Code 与 Agent 工作流：从工具体验、提示词和多 Agent 协作，到项目如何从一句想法走到可运行版本。
