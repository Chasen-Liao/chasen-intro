## 设计判断

面向 AI Coding 同好与潜在合作者的个人站，以暖纸张、编辑式衬线排版、工程蓝图及动漫 IP 为品牌语言；目标是保留式提质，而非视觉重建。

- DESIGN_VARIANCE：7，保留不对称排版并加强作品区主次。
- MOTION_INTENSITY：5，头像材质反馈、入场与操作状态优先，减少持续装饰运动。
- VISUAL_DENSITY：4，以分组和清楚层级替代长表格和微型元数据。
- 技术基础：原生 HTML/CSS/JavaScript，不迁移框架。
- 配色：纸色 `#F4EFE6`、墨色 `#1A1714`、品牌橙 `#F0652E`；新增同色系深橙用于文字，加深辅助灰字以满足对比度。
- 字体：保留 Playfair Display / Noto Serif SC 的品牌展示角色；正文保留干净无衬线，减少微小等宽标签。
- 形状：IP 身份卡保持软圆角；按钮与技术标签使用统一小圆角；截图边框采用同一中圆角尺度。
- 参考图统一使用当前暖纸色浅主题，不在页面中途反转主题。主题功能不在本轮静默扩展。
