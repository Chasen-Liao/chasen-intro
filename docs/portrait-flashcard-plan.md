## 已确认范围

- 分支：`feat/portrait-3d-flashcard`。
- 用户选择：收藏卡 / 镭射闪卡；卡片替代粒子，专注 3D 跟随。
- 首轮只改首页头像区域；本轮用户确认追加首屏四角及底部的蓝图信号线。保留现有文案、CTA、其他分区及 `works.html`；不包含前一轮尚未实施的全站 UI 优化。
- 原先工作区已有 `docs/restoration-plan.md` 的未提交修改，保持原样，不纳入本次功能实现。

## 素材与视觉简报

- 页面构图参考沿用已接受的 `docs/references/hero-avatar-particles-reference.png`：暖纸张、墨黑、橙色、左侧大字和右侧身份视觉；不再复刻该参考中的粒子效果。
- 真实身份素材：`assets/chasen-avatar-smile.png`，ready，不修改源图，不生成头像替身。
- 卡片：右侧蓝图区域中的 3:4 竖向收藏卡，细镭射边框、真实头像、现有身份与位置标签。卡片材质是用户确认的书面设计增量，非新参考图的高保真复刻。
- 背景素材：无；纸纹、网格沿用 CSS。卡框、虹彩、扫光、阴影与文字均为代码原生。
- 前景素材：唯一使用的真实头像；不生成、不采集其他素材。
- 页面配色保持原 token，青色与粉色反光限制在卡片中，不扩散到全站。
- 不增加可点击、翻面、焦点停靠点、自动摇摆、闪烁或传感器权限。
- 实现契约：原生 CSS / Pointer Events / requestAnimationFrame；参考 apple-design 的可打断临界阻尼回正，以及 emil-design-eng / ui-ux-pro-max 的克制动效、触屏和可访问性规则；不添加依赖。

## 可验证行为

1. 鼠标在卡片上移动时，以不随变换抖动的布局坐标计算目标角度；rotateX 最大 ±9°、rotateY 最大 ±12°。
2. 使用保留速度的临界阻尼弹簧，从当前显示值连续追踪；离开时目标回到 0，快速反向或重新进入无跳变。
3. 倾斜与局部虹彩 / 扫光同帧更新，卡片代码只写卡片局部样式；静止且收敛后不保留 RAF 循环。原站已有的纸纹指针位移监听不在本次修改范围。
4. 触屏、coarse pointer、reduced motion 不启用倾斜；偏好动态改变立即复位。卡片没有新增键盘操作，因此不增加 Tab 停靠点。
5. 页面隐藏、失焦、卡片离屏时立即取消 RAF 并复位；图片失败显示现有 Chasen 字标，不显示破损图片。
6. 无 JS 时卡片与真实头像仍可见。
7. 浏览器检查 1665 / 1440 / 1200 / 900 / 375px：标题、卡片与标签无非预期遮挡、页面无横向溢出。

## 第三轮已确认的调整

- 用户明确选择「在当前版本上再放大 11%」和「增强背景线条与流动信号」，不是相对初版的累计 11%。
- 桌面宽度系数 72% → 79.92%，最大宽度 480px → 532.8px；手机上限 294px → 326.34px，平板上限 356px → 395.16px。小屏仍受可用宽度限制。
- 矮屏仍有高度上限，安全余量由 48px 调整为 24px；必要时实际放大幅度小于 11%，不强制溢出。
- 中等桌面尺寸轻微右移卡片，保留姓名和头像之间的空间；指针命中计算改用未变换的布局 offset，保证平移后仍准确且不抖动。
- 暖灰底线使用现有 muted token 提高对比度，橙色短信号加粗为 2px、提高可见度；不添加霓虹光晕、不加密线路、不改 8 秒节奏。
- 本轮只调整既有卡片和信号层，素材、正文、分区及其他全站功能不变。完成后复跑布局、3D 跟随和信号降级检查。

## 第四轮已确认的调整（细线＋颗粒混合）

- 用户反馈不是单纯亮度不足，希望颗粒或线条更多、更密一点，但不影响主界面；ask_user 选择「细线＋颗粒混合」。
- 保持卡片当前尺寸和交互，四角装饰占用范围保持 144×144px（窄屏 96×96px），不往标题、正文、CTA 或卡片面内扩散。
- 每角增加两层较淡的短折线和 12 个静态像素颗粒；每角仅 2 个小点缓慢沿局部线路移动。底部保留两段线路和中央留白，增加一条细轨、颗粒刻度及每段 1 个流动小点。
- 不再提高整体亮度，不加全屏随机粒子、连线网络、霓虹或扫描层。原短信号保持 8 秒节奏，新颗粒以 12 秒错峰轻移；静态密度增加，动态只作为一层边缘氛围。
- 复用现有 Hero 可见性与 motion 生命周期；新增动效仅 CSS transform / opacity，不引入背景逐帧 JS、Canvas、素材或依赖。无 JS / 无观察器静态，reduced-motion 隐藏移动小点并保留静态纹理。
