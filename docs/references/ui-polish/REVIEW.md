## 一致性审查与必须确认的统一规则

生成图在页眉字号、按钮文案、纸色和头像细节上仍有模型差异。它们不能被默认为实现细节；确认本套参考图时，应同时确认以下统一规则：

1. **全局外框**：首页各分区共用同一个页眉，不逐图重做。桌面高度 72px、字标约 26px、导航约 14px；手机页眉约 64px，使用可访问的折叠菜单。全部作品页保留自身导航，不新增仅首页具有的模式切换功能。
2. **配色与字体**：背景统一沿用 `#F4EFE6`，墨色 `#1A1714`，品牌橙 `#F0652E`，文字深橙建议 `#AE3E17`，辅助灰建议 `#665E54`。保留现有字体角色；不照抄生成图中正文变成衬线的偏差，不逐图目测配色。
3. **文案与身份**：主 CTA 始终写「关注 X」，不照抄 Hero 图中缺失 X 的「关注 ↗」。头像必须使用 `assets/chasen-avatar-smile.png` 原文件，禁止使用模型重绘后的脸、服装或细节。已有账号、原链接和版权文字是事实源，不采用作品页图中新增的英文版权句。
4. **素材边界**：项目预览只使用 `sources/` 里有来源记录的真实截图，禁止使用生成参考图里被重绘的 Pi、SuperMew、FOMO 或博客界面。画框、标签、阴影、文字、导航和按钮保持代码原生。
5. **交互**：Social 默认、Resume 切换、筛选、复制微信、键盘焦点、返回顶部与 GitHub 回填继续存在；参考图的模式开关仅表示位置，不作为初始开关状态的事实依据。
6. **形状**：IP 卡软圆角，按钮统一小圆角约 4px，项目图像框统一中等圆角；不复制生成图中不一致的圆角或过重阴影。
7. **手机**：以信息先行、CTA 首屏完整可见为硬约束；头像在 CTA 之后。移动参考图中卡片比最初提示词更大，但整幅仍为单屏比例，这一构图可作为候选。实际几何需在素材清单与浏览器 QA 中测量，不能凭提示词尺寸宣称已验证。

## 单调性审查

- 页面包含：不对称 Hero、分组式信息排版、重点项目加紧凑档案、居中联系收束、非等分三项目展示。
- 没有三个以上分区重复同一个「左文字 + 右视觉」骨架。
- Hero、About、Contact 即使把图像换成灰块，也仍有字号层级与明显构图；Work 的主次档案、作品页的宽窄关系也不只依赖照片内容。
- 同一浅色主题与衬线展示语言贯穿页面。生成图的微小色差按上述统一规则收敛，不把它作为分区换肤。
